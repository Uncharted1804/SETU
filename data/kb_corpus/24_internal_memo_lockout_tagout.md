# Internal Memo — Updated Lockout-Tagout Points for CDU Preheat Train

From: Maintenance Engineering
To: Operations, Inspection
Date: 2025-01-18
Subject: LOTO Point List Revision — E-205/E-210

Following the addition of a bypass line around E-210, two new isolation
points have been added to the LOTO point list for the preheat train.
Updated point list (LOTO-002 Rev 7) is attached to the physical isolation
binder in the control room; all isolation certificates issued before
2025-01-18 using the prior revision should be treated as void for this
equipment.
