# Vendor Correspondence — Meridian Seals Inc.

Date: 2025-01-22
Subject: Voluntary Recall Notice — Gasket Lot GK-2024-77

Meridian Seals is issuing a voluntary recall for spiral-wound gasket lot
GK-2024-77 due to a manufacturing defect affecting compression set above
70°C. If this lot was used on any flange rated above 70°C service
temperature (this includes several CDU preheat train flanges), replacement
is required before the next pressure test.
