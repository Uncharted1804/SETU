# Internal Reference: P&ID Symbol and Tag Numbering Convention

Document ID: ENG-STD-004
Revision: 2

## Equipment Tag Prefixes
- V- : Vessel / Drum (e.g., V-1042, Naphtha Splitter Reflux Drum)
- C- : Column (e.g., C-101, CDU main fractionator)
- E- : Heat Exchanger (e.g., E-205)
- P- : Pump (e.g., P-330)
- R- : Reactor (e.g., R-301, FCC riser reactor)
- TK-: Storage Tank (e.g., TK-12)
- RV-: Relief Valve

## Line Numbering
Format: [Size]-[Fluid Code]-[Line Number]-[Spec Class], e.g.
`8"-CR-1042-A1B` denotes an 8-inch crude oil line, line number 1042,
piping class A1B.

Full P&ID drawings are controlled documents held in the engineering
document management system and are not reproduced in this reference; this
document exists only to support reading tag references found in inspection
findings and correspondence.
