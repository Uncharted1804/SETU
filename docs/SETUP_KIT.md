# SETU Setup Kit

Everything needed to get the RTX 4060 machine ready before the hackathon, derived from
`SETU_final_hackathon_blueprint.md` sections 6, 10.3, 12.2, 12.6 and 15.1.

**Read `SETUP_GUIDE.md` first.** It is the ordered walkthrough; these files are the tools it calls.

## Run order

```powershell
.\scripts\00_env_setup.ps1        # then restart Ollama from the tray
.\scripts\01_pull_models.ps1      # 30-60 min
python .\scripts\02_fetch_embeddings.py
.\scripts\03_build_sandbox.ps1
.\scripts\04_cache_wheels.ps1
                                  # --- T-5 ---
python .\scripts\benchmark_models.py --out docs\BENCHMARKS.md
                                  # update config\models.yaml from the results
python .\scripts\make_allowlist.py --full-hash
                                  # --- T-1, adapter disabled, after reboot ---
python .\scripts\preflight.py --verify-hashes
python .\scripts\offline_check.py
```

## Two things worth knowing before you start

**The benchmark is not a formality.** `qwen3:8b` at 8k context needs roughly 6.3 GB of your
8 GB. Whether it fits depends on what else is holding VRAM. If `ollama ps` shows anything
other than `100% GPU`, demote that slot to the fallback and record why — a 4B model that
answers in 8 seconds beats an 8B model that stalls on stage.

**One blueprint correction is baked into these scripts.** Section 6.2 lists
`OLLAMA_NO_CLOUD=1`, which is not a documented Ollama variable. Don't put it on a slide as
your air-gap control. `00_env_setup.ps1` sets it harmlessly but prints the correction: your
actual proof is the disabled adapter, the `--network=none` sandbox, the process-scoped
socket monitor, and the negative control — which is what §12.3 already argues.

## What still needs your team

These scripts cover environment, models, and proofs. Not covered, because they are P2/P3/P6
build work rather than setup: the demo corpus in `data/kb_corpus/`, the retrieval calibration
set that fills in the `top_k` and `distance_cutoff` nulls in `models.yaml` (blueprint F14
is explicit that you must not ship an uncalibrated cutoff), the DOCX/XLSX templates, and the
chosen demo scan. `preflight.py` will fail on the corpus and index checks until those exist —
that is intentional, not a bug.
